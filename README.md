# 🏥 Hospital Management System

A modern full-stack **Hospital Management System** built with the **MERN Stack**.

This system provides a web-based platform for managing doctors, patients, appointments, departments, and basic hospital operations. It includes separate functionality for **Patients and Administrators**.

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Install Frontend Dependencies

```bash
cd frontend
npm install
```

### 3. Install Backend Dependencies

```bash
cd ../backend
npm install
```

---

## 🔐 Environment Variables

Create your environment configuration file inside the backend project.

Example:

```env
PORT=4000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
```

> Never commit your environment variables or secret keys to GitHub.

---

## ▶️ Run the Project

### Start Backend

```bash
cd backend
npm run dev
```

### Start Frontend

```bash
cd frontend
npm run dev
```

The application will then be available through your local development server.
